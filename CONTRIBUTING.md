# Contributing

Issues are welcome. Pull requests are turned off, because this fork follows how its maintainer works and every line needs to be written and reviewed by them.

If you have a fix, open an issue that describes the problem and how to reproduce it. For a problem that also affects `pi-look`, consider [reporting it there](https://github.com/felipeadeildo/pi-harness/issues) too.

For security problems, follow [SECURITY.md](SECURITY.md) instead.
